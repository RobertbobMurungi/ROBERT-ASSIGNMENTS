# INHERITANCE IN C++

## Meaning of Inheritance

Inheritance is an Object-Oriented Programming feature where one class acquires the properties and functions of another class.

The class whose members are inherited is called the *base class* or *parent class*.

The class that inherits from another class is called the *derived class* or *child class*.

Inheritance helps programmers reuse code instead of writing the same variables and functions many times.
